## 0. 一句话

> 快速权重（fast weights）与线性注意力**在数学上同构**（§2）。
> 因此"可塑性"不可能是"另一种注意力"就赢。
> 唯一值得测的命题是：**当一个固定大小的状态必须跨越上下文边界、并在有限算力下压缩一整条流时，
> 在线可塑记忆是否比"截断上下文"和"等大小 KV（查表）"更好，且优势随流长增长。**

如果答案是否，那么"可塑、有状态"这条路线**在能力层面不存在**，
只剩工程实现差异——这正是要尽早证伪的。

## 1. 先验工作：这不是新的在哪

| 本文涉及 | 已有等价工作 | 关系 |
|---|---|---|
| 快速权重 ΔW=η·(x⊗y) + 衰减 | Hinton & Plaut 1987、Schmidhuber 1992、Ba et al. 2016 | 机制古老 |
| 线性注意力 ≡ 快速权重编程 | **Schlag et al. 2021**（Linear Transformers Are Secretly Fast Weight Programmers） | **同构已证** |
| 推理时在线更新（TTT） | Sun et al. TTT、DeltaNet (Yang et al. 2024)、**Titans (NeurIPS 2025)** | 当前热点 |
| 复杂 fast-weight 参数化仍归结为线性注意力 | **arXiv 2602.21204**（TTT with KV Binding Is Secretly Linear Attention, 2026） | **等价性加强** |
| 固定大小记忆 vs 全上下文 | 线性注意力/RNN vs Transformer 的老问题 | 已知张力 |

**当前最热的方向不是"能不能做"，而是"它是否只是注意力的一种参数化"。**
`[文献]` 2602.21204 的分析结论是：连多层 MLP + momentum 的内循环
也可被改写为**学习式线性注意力**。所以"反复训练权重"未必带来新能力。

## 2. 形式化：为什么"可塑性"可能只是换皮

快速权重（Hebbian 形式）：

```
W_t = λ · W_{t-1} + η · v_t k_tᵀ          # 写
y_t = W_t q_t                              # 读
```

线性注意力（recurrent form）：

```
S_t = S_{t-1} + φ(k_t) v_tᵀ                # 状态就是 W
y_t = S_t φ(q_t)                           # 读
```

**两者是同一个对象**（差一个归一化/φ）。因此：

| 说法 | 是否区分能力 |
|---|---|
| "写/读/忘的规则不同" | ❌ 同一算子族 |
| "参数化更深（MLP fast weights）" | ❌ `[文献]` 2602.21204 仍归结为线性注意力 |
| **"状态跨上下文边界存活"** | ✅ **唯一可能的机制差异** |
| **"固定大小 + 选择性写/淘汰"** | ✅ **唯一可能的机制差异** |

> **结论**：必须把自变量从"是否更新权重"改成
> **"状态的生命周期与容量管理"**。
> 否则实验注定测不出差异（且若测出，多半是算力差异）。

## 3. 核心命题 Q（可证伪）

> **Q**：存在一个**固定大小**的在线可塑记忆，使得在一条**长 episodic 流**上
> （每段上下文会被重置）：
>
> **(a)** 其对早期信息的召回 `acc_C(d)` 高于**等算力截断上下文** `acc_A(d)`，
> 其中 `d` = 信息被写入到被查询之间的"距离（段数）"；
> **(b)** 该优势 `acc_C(d) − acc_A(d)` **随 d 单调上升**（存在有限 `d*`）；
> **(c)** `acc_C(d) > acc_B(d)`，其中 `B` 是**等状态大小、等算力**的 KV/检索（"查表"）。
> 若 `C ≈ B`，则可塑性退化为**记忆管理策略**，"内部权重改变"的说法是空的。

### 为什么 (c) 是分水岭

- `C > B` → 可塑性是**真机制**（学到的东西被压缩进权重，检索拿不到）；
- `C ≈ B` → 它只是**固定大小 KV 的淘汰策略**（已知工程，非贡献）；
- `C < B` → 查表更好，可塑性路线**当场证伪**。

## 4. 与 MioArgus 的关系

MioArgus 的 H1 是"**重观察**替代参数"（环境 ↔ 参数）。
Q 是它的对偶："**持久状态**替代上下文"（权重 ↔ 上下文）。

两条都遵循同一纪律（P9 的教训）：**等算力、单一机制、明确 kill condition**。
这也是本文档刻意只挑一个支柱的原因。

## 5. 最小实验设计（Q1）

### 5.1 环境：episodic association stream（合成、可控、可判）

```
for episode e = 1..E:
    呈现 M 个新关联 (k_i → v_i)   # k,v 来自大词表
    上下文重置（清空窗口）
查询阶段：随机问一个过去 episode 的关联 k，答 v
距离 d = E − e（查询点距写入点的段数）
```

要点：
- **上下文必须真的被重置**——否则注意力可以靠回读作弊（这是等价性的空子）。
- 词表要大（防止答案可猜）；M 可调；可加"关联复现"轴。

### 5.2 四条臂（同参数量、同每步 MACs）

| 臂 | 机制 | 检验 |
|---|---|---|
| **A** 截断上下文 | 只看当前 episode 的窗口 | 基线（健忘） |
| **B** 等大小 KV / 检索 | 存 past KV，超预算 FIFO 淘汰；查询 top-k | 查表基线（§3c 分水岭） |
| **C** 快速权重（门控） | 固定大小 W，surprise 门控写 + 衰减 | 待检验机制 |
| **C0** 快速权重（无门控） | 纯 Hebbian 累加，无衰减 | 隔离"选择/遗忘"是否是机制 |

**参数与算力必须配平**：C 的状态大小 = B 的 KV 预算；每步 MACs 相同。

### 5.3 扫参

`E ∈ {4, 8, 16, 32}`（流长）、`M ∈ {4, 16}`（每段关联数）、
词表 `V ∈ {1k, 10k}`、关联复现率 `∈ {0, 0.5}`。

### 5.4 判据（crossing）

```
存在 d* 使 acc_C(d) > acc_A(d)，且 gap 随 d 单调上升
且 acc_C(d) > acc_B(d)                # 权重 > 查表，否则只是记忆管理
```

### 5.5 杀死条件（任一成立即路线死）

1. `acc_C ≤ acc_A` 对所有 d → 持久状态无价值；
2. `acc_C ≈ acc_B` → 可塑性 = 记忆淘汰策略，"内部改变"是空话；
3. `acc_C0 ≈ acc_C` → 门控/遗忘（可塑性的独特部分）不是机制；
4. 优势在**等 MACs** 下消失（只在更高算力/更多参数下出现）；
5. **灾难性遗忘**：C 完全记不住早期 episode → 连自身核心承诺都没兑现。

### 5.6 度量

`acc(d)` 遗忘曲线、`acc(E)`、最早 episode 保留率、每步 MACs、状态大小、
**写入选择性**（被写入的信息里最终有用的比例）。

### 5.7 Q1 实测（2026-09-19，见 [results/plasticity/Q1_RESULTS.md](..\results\plasticity\Q1_RESULTS.md)）

无训练机制对照已跑（`q1_plasticity.py`，2×2 门控×衰减消融，20 seeds）：

- **sanity 通过**：快速权重能跨上下文边界召回（A 不能）；
- **距离相关**：容量内精确 KV ≫ 快速权重；容量外快速权重 ≫ KV（优雅降级，抗噪更好）；
- **杀死条件 3 触发**：门控效应 ≈ **−0.00 ~ −0.03**（空转/略有害），
  衰减效应 **−0.01 ~ −0.16（一致为负）**。
- **裁决**：压缩式记忆有真实但有限的价值；**"选择性遗忘是机制"未被支持**——
  在本设置里最简单的不门控、不衰减的 Hebbian 累加即最优。
- 局限：无训练（门控"空转"部分源于 surprise 恒高）、查询距离均匀（天然惩罚衰减）。
  这两条是 Q2 的入口。

### 5.8 Q2 实测（2026-09-19，见 [results/plasticity/Q2_RESULTS.md](..\results\plasticity\Q2_RESULTS.md)）

给 Q1 的"均匀查询"辩护各拆一刀（查询距离权重 `w_d=beta^d` + 巩固臂）：

- **衰减是机制，但条件于查询分布**：`decay_eff` 随 `beta` 单调，
  均匀时 −0.14，偏近因（beta=0.5）时 **+0.21**，转正点 `beta*≈0.9`。
  → **部分撤回 Q1 的"衰减有害"**。
- **但精确 KV 在偏近因下依然更强**：`beta=0.5` 时 `B=0.954` vs 压缩记忆 0.783。
  衰减只是"少输一点"，没有推翻有界精确缓冲。
- **巩固一致有害**：`repeat=0.5` 时 `cons_eff = −0.035 ~ −0.165`——
  按频率放大写入会加剧干扰。**"该记什么"仍未被兑现**。
- 修正表述：**遗忘的价值 = f(查询分布)**；不是普适机制，也不是无用。

### 5.9 Q3 实测（2026-10-02，见 [results/plasticity/Q3_RESULTS.md](..\results\plasticity\Q3_RESULTS.md)）

把 Q1/Q2 的手工门控/衰减换成**可学版本**（端到端，梯度穿过写入，
2×2 消融 × noise × beta，完整协议 150 epoch / 1500 流 / 3 seeds）：

- **learned gate ≈ 0**（|Δ| ≤ 0.0004，全部 4 个条件）——
  **杀死条件 3 在训练下稳健成立**："选择性写入"给梯度也学不出来。
- learned decay 只在偏近因下 +0.012 ~ +0.023，均匀 ≈0——
  **维持 Q2 的条件性裁决**，幅度还小于手工衰减。
- 分水岭不变：超容量均匀时 fw(0.55) ≫ KV(0.25)；偏近因时 KV(0.76) 赢。
- 方法学：quick（1 seed/40 epoch）曾给 decay −0.09 ~ −0.34 的**欠训练假象**，
  完整协议翻为 ~0/+0.02 → 单 seed quick 不可作裁决。

**写入侧终态**（§3 命题 a/b/c + §5.5 五条杀死条件的现状）：
sanity 与距离/容量结构成立；`C > B` 只在"超容量 + 查询不偏近因"区域成立；
**选择写入、遗忘、巩固、可学门控——四项机制主张全部未兑现。**
站得住的结论：压缩式状态是**容量受限下的召回工程**，不是新机制。
（Q4 对"选择性写入"补了 oracle 上界与收线裁决，见 §5.10。）

### 5.10 Q4 实测（2026-10-02，见 [results/plasticity/Q4_RESULTS.md](..\results\plasticity\Q4_RESULTS.md)）

回答 Q3 遗留的"headroom 在哪"：重要性偏置查询（hot 分层到各距离，
与 Q2 的偏近因轴无关）× {nogate, learnedgate, oraclegate}，完整协议 3 seeds：

- **oracle 重要性写入有效**：加权召回 +0.018（干净）/ **+0.093（噪声）**——
  选择性写入的价值是**信噪比重分配**，真实存在；
- **learned gate 仍 ≈0**（+0.0001 ~ +0.0008）：hot/cold 是写时不可观测的潜变量，
  Q3 的"该记什么学不出来"在新查询分布下复现；
- **KvOracle（精确+真值淘汰）> O（压缩+真值写入）**：0.600>0.571、0.386>0.303；
- 代价：O 的均匀召回崩到 0.305/0.128——重分配不是免费午餐。

**写入侧最终裁决**：可塑性写入侧的价值是**真实的、次优的、且不可学习的**——
不构成能力主张。**本线收线**（遗留仅剩低优 λ 解耦，不改方向）。

## 7. 风险登记

| 风险 | 说明 | 缓解 |
|---|---|---|
| **等价性把差异吃掉** | C 与 B 数值接近 → 无结论 | 强制"上下文真重置" + 等大小 KV |
| 合成任务太易 | 无梯度 | 大词表、长流、低复现 |
| 门控写不稳定 | 在线更新发散 | 归一化 + 衰减 + 小 η；C0 作对照 |
| "权重 vs 查表"其实是压缩问题 | 不是学习问题 | 明确按 §3c 表述，不夸大 |
| 单 seed | P9 的教训 | 多 seed + 置信区间 |
