# 阈值型指标 预扫描协议模板（v1.0）

> 用途：在**正式预注册与批量训练之前**，证明"阈值型指标"（如 `params_needed(0.80)`、
> "达到 X 准确率所需样本数"、"越过 Y 所需预算"）在**预定实验范围内可估**。
> 适用：任何形如 `f(横轴) → 是否越过阈值` 的指标。不适用于纯对比型指标（如成对 Δ）。
> 来源：H4（126 次训练后才发现主指标两端截断）——见 `results/paper/H4_RESULTS.md` §7。
> 配套门禁脚本：`experiments/paper/prescan_gate.py`（不通过 → 退出码 1）。

---

## 1. 指标定义（先写死，再跑）

| 项 | 必须写明 |
|---|---|
| 目标阈值 | 例：`acc ≥ 0.80`；说明为何选这个值（不是"顺手"） |
| 横轴 | 例：参数量（log 轴）、样本数、交互预算；**必须单调可排序** |
| 计算方式 | 例：相邻两档之间在 log(横轴) 上线性插值 |
| 插值前提 | **曲线在该区间单调**；不单调时不得插值（见 §5） |
| 输出形态 | 点估计 / 下界 / 上界 / `null`；三者不得混写 |
| 不可估时怎么裁定 | **必须预先写明**，且不得解释成"否证" |

## 2. 预扫描设计（不进主分析）

| 项 | 要求 |
|---|---|
| 目的 | 只回答"阈值是否落在扫描区间内部"，不产出任何结论 |
| 规模 | 每条件 **≥1 seed**；样本量/epoch 可缩减（判据是覆盖，不是精度） |
| 记录 | 输出到独立文件（如 `results/<line>/prescan_*.jsonl`），**主分析不得引用** |
| 命名 | 文件名带 `prescan`，报告里标注"预扫描，不参与判定" |
| 禁止 | 用预扫描的数字填主结果表；用预扫描的 seed 冒充主 seed |

## 3. 覆盖检查（两端余量）

对**每个条件、每个 seed**：

```
min(value) < threshold - margin        # 左端：最小档必须在阈值之下
max(value) > threshold + margin        # 右端：最大档必须在阈值之上
```

- `margin` 默认 0.02（防止浮点/噪声造成"刚好压线"的假覆盖）；
- **任一条件不满足 → 该条件下指标不可估，正式矩阵不得启动**；
- 若某条件天然达不到阈值（真实上界），则该条件只能报**下界**（`> 最大档`），
  不能进主分析的点估计表。

## 4. 阈值分辨率

插值只发生在"相邻两档跨越阈值"的那个区间内，因此该区间的宽度直接决定估计质量：

```
ratio = x[k+1] / x[k]      # 跨越点的相邻两档
ratio ≤ max_gap_ratio      # 默认 2.5
```

- 跨越点必须**唯一**（曲线多次穿越阈值 → 说明非单调，见 §5）；
- 跨越区间过宽 → 报区间，不给单点结论；
- 横轴档位应在**阈值附近加密**，远离阈值处可稀疏。

## 5. 异常曲线处理（四类，分别对待）

| 形态 | 判定 | 允许的动作 | 禁止的动作 |
|---|---|---|---|
| **左截断** | 最小档已越过阈值 | 报 `≤ 最小档`；或用更低档补（新预注册） | 把截断值当点估计 |
| **右截断 / 未越线** | 最大档仍未越过阈值 | 报 `> 最大档`（下界）；该条件标 `null` | 外推、用边界值顶替 |
| **非单调** | 曲线先升后降/多次穿越 | 单独报告形态；必要时分段或换指标 | 用单调插值、取"最优档"当代表 |
| **多点穿越** | 曲线两次以上跨阈值 | 报所有穿越点，说明不稳定 | 只取第一次/最后一次 |

> 反降曲线（如噪声背景下的过拟合）是一类**独立机制**，不得并入单调规模曲线。

## 6. 开跑门禁（自动化）

```powershell
python experiments/paper/prescan_gate.py `
  --runs results/<line>/prescan_x.jsonl `
  --threshold 0.80 --monotone --max-gap-ratio 2.5 --report results/<line>/PRESCAN_REPORT.md
```

门禁检查（任一 FAIL → 退出码 1，正式矩阵**不得启动**）：

| 门 | 检查 |
|---|---|
| G0 | 结构：每条件 × 每 seed 的横轴档位一致（同一网格、同一配对任务流） |
| G1 | 严格内部：`min < threshold < max`（每个条件、每个 seed） |
| G2 | 左端余量：`value(x_min) < threshold - margin` |
| G3 | 右端余量：`value(x_max) > threshold + margin` |
| G4 | 分辨率：跨越点唯一，且相邻档 `ratio ≤ max_gap_ratio` |
| G5 | 单调性：声明用单调插值时，曲线必须符合方向（`--monotone-dir up` 用于阈值型指标；**H 曲线用 `down`**）；容差默认 **0.05 ≈ 3×SE**（`n_test=1000`），即反向抖动 <5pp 视为噪声 |

### 6.1 两种模式

| 模式 | 参数 | 适用 | 门 |
|---|---|---|---|
| A 阈值型 | `--threshold 0.80 --monotone-dir up` | "达到 X 所需代价" | G1–G5 |
| B 区间型 | `--band 0.2,0.9 --monotone-dir down` | KPI 是**动态范围**（如"每个 H 都要可测"），而不是越线 | B1（每点都在 `[LO+margin, HI−margin]` 内）+ G5 |

B 模式是为 E1-L 的 M1 前置设计的：要求 `cls` 在 H=1..8 **每个点**都落在 [0.2, 0.9]，
而不是"某个阈值被跨过"。用 A 模式检查这类需求会得出错误结论。
注意方向：任务成功率随 H **下降**，所以 B 模式的单调方向是 `down`（用错方向会把正常曲线判成违规）。

**铁律**：

> 只要任一条件的阈值不在扫描区间内部，或曲线非单调却仍计划使用单调插值，
> 正式实验不得启动。

## 8. 反例（本模板的由来）

H4 主指标 `params_needed(0.80)` 在 7 档 width 内**两端同时截断**：

| 条件 | 问题 | 本模板的哪一关会拦住 |
|---|---|---|
| C0 | w4 已 0.938 → 左截断 | G2 |
| C2 / C3 | w32 仅 0.778 / 0.602 → 未越线 | G3（且 G1） |
| C4 | w4 已 0.899，且随 width 反降 | G2 + G5 |
| C3 | 曲线非单调（w12 0.570 → w16 0.496） | G5 |

若当时先跑 1 seed × 7 档（约 1/3 的墙钟时间）再过门禁，这 126 次可以在**第一批 6 次之后**被拦下。

**门禁实测**（`experiments/paper/prescan_gate.py`，报告见 `results/paper/PRESCAN_H4_GATE.md`）：

```
python experiments/paper/prescan_gate.py --runs results/paper/h4_density_runs.jsonl \
  --x-col params --value-col acc --threshold 0.80 --monotone

→ FAIL：C0 [G1,G2]　C1 [G5]　C2 [G1,G3,G5]　C3 [G1,G3,G5]　C4 [G2,G3,G5]　C5 [G5]
```

同一门禁在一组合格的合成预扫描数据上返回 **PASS**（退出码 0），说明它不是"永远拒绝"的摆设。
