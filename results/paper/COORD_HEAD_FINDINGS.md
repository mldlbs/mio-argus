# 坐标头诊断：0/84 是标签缺陷 + 输出收缩，不是表征缺失

> 日期：2026-11-22　范围：**零训练**，168 条带坐标样本（84 click + 84 move）的前向 + 线性探针。
> 触发：`H_CROSSING_SMALL_ARM_AUDIT.md` 判"小模型臂没有定位能力"，需要区分
> **表征里没有位置** 与 **头/目标没学会**。
> **结论：表征里有位置（跨屏 LOOCV R² x=0.71 / y=0.91），坐标头被告知了 336 个假目标 (0,0)。**
>
> **v1.1 更正（同日，见 `COORD_RETRAIN_RESULTS.md`）**：修正掩码后重训 1 次，
> 掩码缺陷**确实是缺陷但不够**——x 仍 0.203、命中仍 0/168；同构读出换成长训练/闭式解能把
> x 打到 0.118，但 `±2%` 命中上限只有 **4/168**。⇒ 本文件 §0 的"主因"表述**被部分否证**：
> 真正的地板是**768 维全局池化读出的精度**，不是标签、也不是训练步数。

---

## 0. 一句话

`coord_head` 的输出不是"学不会"，是"被训练成保守值"：

- 504 条训练样本里 **336 条（66.7%）没有 x/y**，但 `coord_mask` 恒为 `True` → 目标被写成 **(0,0)**；
- 全体 x 目标**中位数 = 0.000**、零值占比 0.667；Huber(δ=0.1) 在该比例下近似 L1，
  最优解就是**条件中位数**；
- 实测输出：84 条 click 上预测 x = **0.646 ± 0.027**（真值 0.551 ± 0.249），
  标准差被压小 **约 9 倍**，与真值相关仅 **+0.31/+0.76**。

即：头学到了"点大概在哪一片"，然后把分布压扁到命中不了任何 20px 目标。

## 1. 方法

| 项 | 做法 |
|---|---|
| 样本 | `balanced_training_data.json` 中带 `x/y` 的 **168 条**（click 84 + move 84） |
| 特征 | 在 `out_proj` 前挂 hook，取 **fused_last（768 维）**；另取 ViT patch 均值 / CLS（768 维） |
| 读出 | 对偶形式 kernel ridge，**精确 LOOCV**（hat 矩阵），λ 扫 1e-3…1e4 |
| 对照 | ① `coord_head` 原始输出 ② 均值基线 ③ **打乱标签**同流程（查标签泄漏） |
| 分辨率 | 224（与训练一致），图像 2560×1440 → 224；坐标按逻辑屏 1920×1080 归一 |

**跨屏性**：504 张截图**互不相同**（md5 去重 504/504），因此 LOOCV = **留一屏**，
探针不是记住了同一张图。

## 2. 结果（同一批 168 条样本）

| 方式 | MAE x | MAE y | 像素 x | 像素 y | R² x | R² y | 命中 ±2% |
|---|---|---|---|---|---|---|---|
| `coord_head`（现状） | 0.2055 | 0.1905 | 395 | 206 | −0.014 | +0.074 | **0/168** |
| **线性探针 fused**（λ=0.01） | **0.1045** | **0.0538** | **201** | **58** | **+0.710** | **+0.914** | — |
| 均值基线 | 0.2161 | 0.2111 | 415 | 228 | 0.000 | 0.000 | 0/168 |
| 打乱标签对照 | 0.2161 | 0.2111 | — | — | ≈0 | ≈0 | — |

分动作：

| 子集 | `coord_head` MAE | R² | 命中 |
|---|---|---|---|
| click（84） | x=0.2019 / y=0.1946 | −0.089 / −0.014 | 0/84 |
| move（84） | x=0.2092 / y=0.1864 | +0.039 / +0.117 | 0/84 |

另两个特征（次要，但方向明确）：

| 特征 | 最优探针 | 读法 |
|---|---|---|
| ViT patch 均值 | R² ≤ 0（所有 λ） | 池化后不含线性可读位置 |
| ViT CLS | R² ≤ 0（所有 λ） | 同上 |

**即位置信息是在 LoRA + 跨模态融合之后才线性可读的**，不在冻结 ViT 的池化特征里。

## 3. 标签缺陷（已证事实）

```
总样本 504：click 84 / move 84 / type 84 / scroll 84 / hotkey 84 / press 84
没有 x/y 的样本：336（66.7%）→ coords 目标 = (0,0)，coord_mask = True
全体 x 目标：中位数 0.000　均值 0.175　零值占比 0.667
```

`mio_argus.compute_loss` 的 `coord_mask` 机制本身是对的（per-sample 掩码、scalar 掩码都有测试），
`train_inloop.py` 也一直按 `has_xy` 置掩码——**只有 `train_computer_use_v3_real.py` 恒置 True**。

## 4. 边界（不可外推的部分）

1. 168 条样本、**单一应用、单一逻辑屏（1920×1080）、单一采集管线**；
2. λ 是在同一 LOOCV 上选的，R² 可能**略偏乐观**；
3. 线性探针 ≠ 端到端能力：探针用的是 768 维表征 + 全量样本拟合，头要在线性层后接 dropout 与 sigmoid；
4. **x 探针 201px 仍远大于 216 清单的中位目标 20px**——本文件**不能**推断"修好头就能命中目标"；
5. 本文件**不**改判 H-Crossing 可建：它只说明"上一份审计把原因归错了"。

## 6. 仪器工单

| # | 内容 | 状态 |
|---|---|---|
| W1 | `train_computer_use_v3_real.py` 的 `coord_mask` 改为 `has_xy`（click/move 才参与 coord loss） | **已改**（本次，168/504 参与，已验证） |
| W2 | `evaluate()` 补坐标指标：MAE、±2% 命中、**预测 std / 真值 std** | 待批（判据见 W4） |
| W3 | 掩码修复后重训 **1 次**（30 epoch，单卡约 0.5–1 小时，未实测） | **需批准**（训练次数目前仍为 0） |
| W4 | 重训判据（不用拍阈值，用三组比较） | 与 W2 一起冻结 |

**W4 的三条比较**（都相对量，避免又一次"选个阈值"）：

1. 头的 MAE 是否 **≤ 探针 MAE**（0.105 / 0.054）→ 头是否已用尽表征；
2. 头的 MAE 是否 **≪ 均值基线**（0.216 / 0.211）→ 是否真的在定位；
3. `std(pred)/std(truth)` 是否 **> 0.5** → 是否还在收缩；
4. 若三条都不满足，下一步不是加数据，是**换读出结构**（例如 patch 级注意力头），
   因为表征已被证明够用。
