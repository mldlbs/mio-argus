## 0.1 边界声明（先钉死，防止结论越界）

原始假设 H 要求 `|θ_large| ≈ 10¹⁰`。E1-L 的"大模型"臂只有 **≈1.5×10⁶** 参数，
与原始要求相差 **约 4 个数量级**。

因此 **E1-L 的能力边界**是：

| 能 | 不能 |
|---|---|
| 检验**有限规模范围内**（10× 差）参数规模 × 观察间隔的**交互** | ~~证明原始 H（crossing）成立~~ |
| 检验"限定条件下，小模型优势是否随观察间隔增长" | ~~否证原始 H~~ |
| 给出 `H*` 是否在 10× 规模差内出现的**趋势证据** | ~~外推到 10¹⁰ 规模~~ |

**写作纪律**：E1-L 的结果只能写成
「在 10× 规模差内，观察间隔与参数规模的交互效应为 X」，
不得写成「H 成立 / H 被否证」。

## 1. 实验 E1：参数规模 × 观察间隔（2×3 因子）

### 1.1 设计

| 因子 | 水平 | 说明 |
|---|---|---|
| **参数规模** | `small`（≈1.06×10⁵，width 32）/ `large`（≥10×，width 128 ≈ 1.5×10⁶） | 受单卡限制，**不可能达到 10¹⁰**，故本实验命名为 **E1-L（限定版）** |
| **观察间隔 k** | `k=1`（每步观察）/ `k=H/2` / `k=H`（开环） | 沿用 P1 的 `t % k == 0` 语义 |
| **环境变化率 ρ** | 0.3 / 1.0 | P1 已证明 ρ 是必要变量；ρ=0 作为阴性对照 |
| **步长 H** | 1 / 2 / 4 / 8 | 与 P1 对齐，便于复用 |

任务与渲染沿用 `p1_horizon.py` 的 6×6 合成环境，**只加一个参数轴**，不改环境。

### 1.2 必须记录的量

| 量 | 定义 |
|---|---|
| `S` | 任务成功率（按 H、ρ、k、size 分层） |
| `F(θ)` | 单步前向 MACs（脚本内已有 `width_macs` 表可复用） |
| **`C(θ,H)`** | `F(θ) × 平均步数`，**首次纳入成本口径** |
| `H*` | 小模型成功率首次 ≥ 大模型的步长（若无交叉记 `None`） |
| 天花板告警 | 任一格子 `S > 0.95` 或 `< 0.10` 即触发重设难度 |

### 1.3 预注册判定标准

| 判定 | 条件 |
|---|---|
| **支持 E1-L 限定结论** | 存在有限 `H*`；对 `H ≥ H*`：`S_small(k=1) ≥ S_large(k=1)` 且 `C_small ≤ C_large`；且 `(S_small − S_large)` 随 H **单调上升**（Spearman ρ>0，p<0.05） |
| **否证（限定版）** | 对所有 H：`S_large ≥ S_small`，且差值随 H 的斜率 95% CI 覆盖 0（无交叉趋势） |
| **无法判断** | 出现天花板（任一臂 >0.95 或 <0.10）→ 调 `fill`/`ρ` 重跑，**不得**在饱和数据上宣称结论 |
| **限定声明** | 无论支持还是否证，结论都只覆盖 **10× 规模差**；**不得**外推到 10¹⁰，**不得**改写为"原始 H 成立/否证" |

### 1.4 统计与样本

- 每个格子 **≥300 个任务**，固定 seeds ≥3（模型训练种子）；
- 报告均值 + bootstrap 95% CI（1000 次）；组间用 Welch / Mann-Whitney；多重比较 Holm；
- **必须报效应量**（Cliff's δ）；只报 p 值不算结论。

### 1.5 成本估计与前置条件

| 项 | 估计 |
|---|---|
| 训练 | width 128 ≈ 1.5M 参数，25 epochs × 4k 样本 ≈ 单卡 20–40 分钟/臂 |
| 总时长 | 2 规模 × 3 观察水平 × 2 ρ × 3 seeds ≈ **36 次训练，预计 12–20 小时**（可分批） |
| 前置 | `p1_horizon.py` 增加 `--width` 与 `--size-arms`；**不改环境**（改动 < 80 行） |
| 风险 | width 128 可能仍不足以形成交叉 → 那就是"限定版否证"，同样是有效结论 |

### 1.6 范围锁定（防止 E1 无限扩张）

1. **只跑预注册的 36 次训练**（2 规模 × 3 观察水平 × 2 ρ × 3 seeds）。要加臂/加因子，
   必须**重新写一份预注册**并在 `EVIDENCE_MATRIX.md` 追加版本号，不得口头追加。
2. **不得按中途结果修改成功标准**。判据以 §1.3 为准，冻结于本文件。
3. **不得在看到结果后再换成本口径**（例如从 `F × steps` 换回只报成功率）。
4. 若 36 次跑完仍"无法判断"，**停止该实验**，先做难度标定，不得直接扩规模重跑。

## 2. 与 E1 配套的两项低成本实验（都在 E1 之后，视结果决定）

### E1-b 解析器质量 × 动作空间（回答 H2 的真实价值）

- 因子：`parser_recall ∈ {1.0, 0.95, 0.85, 0.7, 0.5}` × `{cls, reg}`
- 判定：找到 `cls` 被 `reg` 反超的 recall 阈值；若 ≥0.95 就已反超 → **H2 在实际系统中无价值**。
- 成本：约 2 小时（复用 P7 环境，只改 recall 注入）。

### E1-c H3b 的泛化

- 在"进度信号弱/延迟/有噪声"三种设置下重测 verifier 增益；
- 判定：若增益在噪声 ε>0.1 时消失（`p6` 已显示 H8 从 0.945 掉到 0.42），则 H3b 的适用边界要写死。
