## 1. 用现有数据先做 A2 预判（这一步就能给出结论方向）

A2 要求的是"**同一任务域内，各臂都在 [0.2,0.9]**"，因为 crossing 必须在同一域上比较。

| 臂 | 真实 GUI（域外/域内） | 合成 UI（域内/域外） |
|---|---|---|
| 220M（训练在合成 UI） | 域外；唯一测过的旧基线是 0.056（地板）；**当前 220M 未测** | **域内**；P0/H4 单步 0.94–0.999（**天花板**） |
| UGround-2B（GUI 预训练） | **域内；0.491（区间内）** | 域外；未测（预期低） |
| qwen3-vl:8b | 域内；未测 | 域外；未测 |

**预判**：

- 真实 GUI：小模型在地板（0.056 或更低）→ **不能测 crossing**；
- 合成 UI：小模型在天花板（≈0.95+）→ **不能测 crossing**；
- 两个 2B 臂在合成 UI 上大概率也在地板（且在**图标任务上实测为 0**）。

→ **在现有资产下，A2 无论选哪个域都会 FAIL**，而且失败原因是**域偏移**，不是难度设置。

这正好印证设计稿 §5 的判断：**域效应比规模效应更大**。要进入 A2，必须先把"适配"变成正式因子，
而不是调难度。

## 2. A2 的判据（先写死）

对选定测试域 `D`，三个臂（220M / UGround-2B / qwen3-vl:8B）各自：

```
PASS(D) ⇔ 0.2 + margin ≤ 成功率 ≤ 0.9 − margin     （margin = 0.05，即 [0.25, 0.85]）
```

- **要求三臂同时 PASS**：crossing 需要同域可比，任一臂在地板/天花板即不可测；
- 域内/域外**分别报告**，不加权、不平均；
- 若某臂因**能力缺失**（grounding-only 无法完成需要 type/scroll 的任务）而失败，
  该任务必须移出主比较集，并在能力矩阵里登记（不是"调难度"）。

## 3. 需要的**新增**测量（仅这些，且分两阶段）

### 3.1 阶段 A：静态（0 推理）

| 项 | 内容 | 产出 |
|---|---|---|
| A2-a | 冻结清单复核：216 条是否覆盖 click-only + 长任务前缀 | 清单统计 |
| A2-b | 当前 220M 与 216 清单的**接口核对**（输入分辨率/归一化/要求） | 接口差异表 |
| A2-c | 合成 UI 的 click 子集能否自动判分、能否复位 | 可判分率 |
| A2-d | 任务能力矩阵：需要 type/scroll 的占比 | 覆盖率 |
| A2-e | 功效：为检测 δ=0.10 所需任务数（Wilson） | n 需求表 |

### 3.2 阶段 B：最小推理（**需另行批准**）

只跑"每臂 × 域"的**一次**通过性测量，不做闭环：

| 臂 | 真实 GUI（216 冻结） | 合成 UI（click 子集） |
|---|---|---|
| 220M | 需新测（1 次前向/样本，≈40 ms/样本） | 已有 ≈0.94–0.999（P0/H4） |
| UGround-2B | 已有 0.491 | 需新测（22.9 s/样本，**最贵的一项**） |
| qwen3-vl:8B | 需新测（HF 4-bit 未验证加载） | 需新测 |

> 成本提示：UGround 在真实 GUI 上 p50 = **22.9 s/样本**，216 条 ≈ **82 分钟**；
> 这是 A2 阶段 B 的主要开销，必须先批准再跑。

## 4. A2 的三种结局与对应动作（先约定，避免事后解释）

| 结局 | 条件 | 动作 |
|---|---|---|
| **通过** | 三臂在**同一域**内都落在 [0.25, 0.85] | 进入正式预注册（M2） |
| **不通过（域偏移）** | 某臂在地板/天花板，且原因是训练域 | **加适配因子**（SFT/LoRA），把适配成本单列，重新审计；**不调难度** |
| **不通过（能力缺失）** | 因 click-only 之外的动作无法完成 | 明确主比较集 = click-only 交集；其余动作只作能力分层报告 |

**禁止**：为了让某臂进区间而下调任务难度、删任务、换种子、或只报告通过的那一臂。

## 5. 已知会阻塞 A2 的两件事（现在就能说）

1. **合成 UI 的天花板**：220M 在合成域 0.94+，任何"难度不变"的 click 子集都会落在天花板
   → 要么换更难的任务族，要么承认该域不可用于 crossing（不是调参问题）；
2. **图标任务 = 0%**：两个 grounding 臂在无文字标签的任务上实测为 0，
   这类任务不能进主比较集，否则必然地板。

## 6. 立即可做的静态动作（不需要推理，建议先做）

1. 复核 216 条清单里 **含文字标签 vs 纯图标** 的比例（AUDIT.md 有 28 条纯图标，需确认全集口径）；
2. 用现有 checkpoint 的接口配置核对 220M 是否**能**吃这 216 张图（分辨率、归一化、输出格式）；
3. 算"检测 δ=0.10 所需样本量"（n≈？），决定阶段 B 的最小规模；
4. 对合成域，列出"当前难度下 220M 必然天花板"的证据（P0/H4 数字），
   据此判断合成域是否只能作**对照臂**。

## 7. 不做的事

- 不在本方案里启动任何推理；
- 不下载 17 GB 权重（除非阶段 B 批准走 HF 4-bit）；
- 不因为某臂不达标而调难度或改判据；
- 不把域内/域外结果平均。
