## 0. 审计结论（先于设计）

### 0.1 现有可用资产

| 资产 | 位置 | 状态 |
|---|---|---|
| 解析器质量注入阶梯（`jit/drop/spurious/shrink`，recall 1.0→0.70） | `p0_select.py` `LEVELS` | ✅ 可直接复用 |
| 真实 CV 解析器（`cheap_parse`，layout 密度 → recall 0.845~0.905） | `p7_realistic_ui.py` | ✅ 存在 |
| 选择模型（任意元素集合上做 id 分类） | `p7_realistic_ui.py` `SelNet` | ✅ 存在 |
| 坐标回归基线 | `p7` / `p0_models.P0Net(reg)` | ✅ 存在 |
| 固定测试集 | `p0_cache/*.npz`（seed=999）+ rollout 固定种子 | ✅ 可用 |

### 0.2 阻塞原因（两条，均为硬阻塞）

**B1 — 指标被 M3 污染**：在本环境里，`cls` 的唯一有效线索是**标签专属颜色**（M3：`by_label` 1.000 vs `permuted` 0.0285）。
因此"解析器质量 × 结构化选择"的网格，实际测的是**"颜色匹配 + 解析器召回"的耦合**，
不能回答"结构化动作是否依赖解析器质量"这个 H2 问题。

**B2 — 缺少带解析器的多步 runner**：`p1_horizon` 是"无解析器"的多步；`p7` 是"有解析器"的单步。
两者没有交集，做 E1-b 需要新写 ~200 行 runner（解析出的可变元素集 → 选择 → 坐标 → 多步推进）。

### 0.3 结论

**不执行 E1-b。** 若强行按"解析器网格"跑，得到的只会是"颜色匹配在解析器缺失时也会掉"这一平凡结论，
且容易被误读成 H2 的证据。缺的不是样本量，是**环境下缺少第二种可识别线索**（形状/文字/位置语义）。

### 0.4 解除阻塞需要什么（属环境改造 M1，不在本次授权范围）

| 编号 | 条件 |
|---|---|
| U1 | 环境为每个元素提供**颜色之外的稳定线索**（字形/图标形状/文本），使 `cls` 在 `permuted` 下仍可解 |
| U2 | 或者换到真实 UI（DOM/a11y 可得）作为解析器质量的来源 |
| U3 | 具备带解析器的多步 runner（B2） |

## 1. 假设（前置条件满足后才检验）

> **H2-P**：结构化动作（在元素集合上做选择）相对坐标回归的优势，随**解析器召回**单调下降，
> 并在某个阈值 `r*` 处被反超。

**可证伪形式**：

| 结果 | 判定 |
|---|---|
| 存在 `r* ∈ [0.5, 1.0]`，且 `r < r*` 时 `reg > cls`（配对差 CI 不含 0） | H2-P 成立（优势有边界） |
| 全部 `r` 上 `cls ≥ reg` | H2-P 否证（结构化优势不依赖解析器） |
| 全部 `r` 上 `cls < reg` | H2-P 否证（结构化无优势） |

## 2. 主指标与对照（草案）

| 项 | 定义 |
|---|---|
| **主指标** | **端到端成功率**：解析器产出元素集 → 策略选择 id → 映射为坐标 → 判定命中（不是模型内部准确率） |
| 对照 1 | 坐标回归（无解析器） |
| 对照 2 | `cls` + 完美解析器（oracle，上界） |
| 自变量 | 解析器召回梯度 `r ∈ {1.00, 0.90, 0.80, 0.70, 0.60, 0.50}`（`drop` 注入，`spurious` 固定 0） |
| 控制变量 | 元素数、布局、渲染、训练预算、任务流（seed 固定） |

## 3. 样本量与统计（草案）

- 每格 `n_tasks = 1200`，3 个训练种子，rollout 种子固定；
- 逐点报告成功率 + t 区间；`r*` 用**配对差**（cls − reg）首次跨 0 的位置估计，并给 bootstrap 区间；
- 多重比较 Holm；效应量必报。

## 4. 停止规则（草案）

1. 若 `r*` 不落在 `[0.5, 1.0]` → 判"无法定位阈值"，**不追加梯度点**；
2. 若任一格出现天花板（>0.95）或地板（<0.05）→ 先调难度，不得在饱和数据上下结论；
3. 总训练次数上限：`6 梯度 × 3 种子 × 2 臂 = 36`，跑完即止。

## 5. 结论边界

- 只回答"H2 的优势是否依赖解析器质量"；
- **不得**恢复被 M3 作废的 `cls` 证据；
- **不得**据此改判 H2 的总体裁定（仍需 U1/U2 的环境支持）；
- 不涉及 E1-L，也不涉及 crossing。
