# 证据缺口与冲突（P0–P9 只读审计）

> 配套文件：`EVIDENCE_MATRIX.md`（逐实验数值）、`NEXT_EXPERIMENT.md`（下一步）
> 本文只回答两件事：**哪里对不上**、**哪些假设可以停 / 必须补**。

## 1. 证据冲突（必须先处理，否则结论不可用）

### C1 — P2 的关键数字在 JSON 里找不到（**最严重**）

| 来源 | 数值 |
|---|---|
| `P2_RESULTS.md` | score 最大绝对差 **0.007153**；"联合 **0.5960** < π top-1 **0.8600**"；"0.86→0.60" |
| `p2_verifier_results.json` | `single_step`: pi_w32 1.0 / pi_w64 1.0 / v_alone 1.0；`diagnostics`: `ceiling_topk` 1.0、`v_pick_given_in_topk` 1.0、`joint` **1.0** |

→ JSON 是**饱和**的，报告里那组"策略弱、V 拖后腿"的数字没有对应文件。
可能原因：`p2_verifier.py` 后来被改成更简单的设置并覆盖了 JSON；`p2_equiv_check.py` 没有 `__main__`，其输出未被保存。

**处理**：H3a 的结构性论证（V 与 π 同构 ⇒ 不可能超越 π）仍成立，但**该实验的实证部分降为 C**；
若要保留"0.86→0.60"这个数字，必须重跑并落盘，否则从报告里删掉。

### C2 — H2 在"真实解析器"下反转

| 实验 | 结论 |
|---|---|
| P0（完美元素） | `cls` 1.000 vs `reg` 0.511（fill=0.4）→ 结构化大胜 |
| P7（解析器 recall 0.845） | `cls_parser` 0.833 vs `reg` **0.977** → 回归反超 |
| P8（学习式解析器） | `recall` 0.518 / `iou` 0.213 → 真实解析器远达不到 P0 的前提 |

→ 两者不矛盾，但**边界条件从未写进结论**：H2 的收益 = `min(结构化收益, 解析器召回)`。
按当前证据，**在没有可靠解析器时，H2 不成立**。

### C3 — 核心假设 H（crossing 曲线）**从未被检验**

`HYPOTHESIS.md` §3 要求 `S(θ_small)/S(θ_large)` 随 H 单调上升，且 `|θ_large| ≈ 10¹⁰`。
全部 P0–P9 的模型规模在 **4,208 – 848,768** 参数之间，**没有任何大模型臂**，
也没有测端到端成本 `C(θ,H) = F(θ) × steps`。

→ 这不算"证据弱"，是**这条假设至今没有实验**。所有"小模型够用"的结论都是在没有对手的情况下得出的。

### C4 — 报告摘要与实验结果不一致（选择性表述）

| 实验 | 实验结果 | `REPORT.md` 摘要 |
|---|---|---|
| P9 主动缩放 | 12 格中 **9 格 random ≥ glimpse** | 摘要未提；只有 `P9_RESULTS.md` 写了 |
| H4 机制 | 噪声（熵最高）优于低频色块（熵较低） | 摘要仍写"低熵"，未用"同类干扰项"表述 |
| Q1–Q4 | 学习式门控 ≈ 无门控（B−A ≈ 0.0008） | 摘要未提 |

→ 不是造假，但**摘要读者会得到比实验更强的印象**。建议按本文件 §3 的判定重写摘要。

### C5 — verifier 的 `acc=1.0` 可能是阈值假象

`p6a_v_stability_results.json`：同一配置 6 个种子的 `acc@0.5` 为 **0.979 / 1.0 / 1.0 / 0.62 / 0.491 / 0.968**，
而 `acc@best` 全为 1.0（`best_thr` 在 0.0007 – 0.98 之间漂移）。

→ P3 的 `V.acc=1.0` 若是在测试集上挑阈值得到的，则**高估**。
需要一条"只用验证集选阈值"的记录（`p6a` 的 `calibrated` 字段显示部分种子 thr 极低，存在此风险）。

## 2. 证据缺口（按"缺什么"分类）

| 缺口 | 影响的假设 | 说明 |
|---|---|---|
| **无大模型基线** | H（核心）、H1 | 无法计算 crossing，也无法说"替代参数" |
| **无端到端成本** | H(b) | `C = F × steps` 全项目未测；闭环步数变多的代价没算 |
| **无参数规模扫描（H2）** | H2 | P0 固定 width=32，"少参数"未验证 |
| **解析器质量未做网格** | H2 | 只有 recall 0.845 / 0.518 两个点，缺 recall × 动作空间 的相变点 |
| **外部效度未验** | H3b、H4 | 全部在 6×6 合成网格上；P7 是唯一"更真实"的设置 |
| **verifier 依赖完美进度信号** | H3b | `V.acc=1.0` 意味着任务可机械判定；无信号环境不适用（`HYPOTHESIS.md` 已注明，但无实验） |
| **阈值选择协议缺失** | H3b、P6 | 见 C5 |
| **成本/延迟未记录** | 全部 | 所有实验只报成功率与时延（`train_s`），无推理成本 |

## 3. 逐假设裁定（五分类）

| 假设 | 裁定 | 依据 | 行动 |
|---|---|---|---|
| **H（核心 crossing）** | **无法判断** | 缺大模型臂与成本测量（C3） | **先修复实验设计**（见 `NEXT_EXPERIMENT.md`） |
| **H1 重观察** | **初步支持** | P1：ρ=0.3,H=8 的 gap +0.923；ρ=0 时无影响 | 补"参数 × 观察间隔"2×3 因子，检验替代关系 |
| **H2 动作压缩** | **初步支持（强边界）** | P0 支持；P7/P8 在真实解析器下反转（C2） | 补参数扫描 + 解析器质量网格；在结论里写死边界 |
| **H3a 重新接地** | **已否证**（结构上） | V 与 π 同构；实证数字不可追溯（C1） | **停止投入**；报告里删掉无源数字 |
| **H3b 结果验证** | **已支持** | P3：增益随 H 上升、达到 oracle 上界、V 仅 6,393 参数 | **转泛化验证**（不同任务族 + 真实环境 + 无信号对照） |

## 4. 值得继续 vs 不值得继续

### 不值得再做

1. **学习式门控 / 可塑性**（Q1–Q4）：多组实验均无增益，除非换机制（如显式记忆库 + 检索）。
2. **"主动"缩放策略**（P9）：随机同等或更好；继续调策略是浪费。
3. **重新接地式 verifier**（H3a）：结构上不可能超越同 backbone 的策略。

### 值得继续（按价值排序）

1. **核心 crossing 实验**：唯一能回答项目主张的实验，且从未做过（C3）。
2. **解析器质量 × 动作空间**：决定 H2 在现实中是否有价值（C2）。
3. **H3b 的泛化**：已成立，需要证明不是"完美进度信号"的产物。
4. **H1 的替代关系**：只需在现有 P1 上加"参数轴"，成本低、结论关键。

---

## 5. 一句话

**P0–P9 真正证明的只有三件事**：结构化动作在完美解析下更鲁棒（有边界）、结果验证有效、干扰项而非熵决定成本。
**而项目最核心的那条主张（小模型靠闭环在长任务上反超大模型），至今没有任何一次实验。**

## 6. 研发方向冻结（2026-11-17 裁定，正式版本）

| 方向 | 裁定 | 依据 |
|---|---|---|
| **H3a 重新接地** | **停止** | 结构上 V 与 π 同构；关键实证数字不可追溯（C1） |
| **Q1–Q4 可塑性门控** | **停止** | 学习门控 ≈ 无门控（B−A ≈ 0.0008） |
| **P9 主动缩放** | **停止** | 12 格中 9 格 `random ≥ glimpse` |
| **H3b 结果验证** | **转泛化验证** | P3 App 级证据（增益随 H 上升、达到 oracle 上界） |
| **H4 同类干扰项机制** | **转泛化验证** | P5 A 级；表述由"低熵"改为"同类干扰项成本" |
| **H1 重观察** | **等待 E1-L** | 只证明"必要"，未证明"替代参数" |
| **H2 动作空间压缩** | **保留边界，补充验证** | 完美解析下成立；解析器 recall 0.845 时被 `reg` 反超 |
| **H 原始 crossing（10¹⁰）** | **尚未检验** | E1-L 只有 1.5×10⁶，仅能覆盖 10× 规模差的限定结论 |

**冻结的含义**：不再投入新实验；已有代码与结果保留，仅作对照与复现用途。

**版本记录**：本裁定与 `EVIDENCE_MATRIX.md` / `NEXT_EXPERIMENT.md` 一并提交，
作为 P0–P9 阶段的**正式证据基线**；后续结论若与本基线冲突，必须显式写"推翻了哪一条"。
