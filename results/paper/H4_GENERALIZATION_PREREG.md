## 0. 审计结论与本次定位

| 项 | 结论 |
|---|---|
| P5 能否作为 C0/C4/C5 的对照 | ❌ **不能**（单次运行、`inst_dim=32`、任务流不可复现） |
| P5 的地位 | 仅背景讨论与动机引用 |
| 本次运行数 | **126 = 6 条件 × 7 width × 3 seed**，不缩减、不追加 |
| 主指标 | `params_needed(0.80)`（四元组下标 1；**不使用 P5 判定所用的 p@0.90**） |

**为什么不用 90 次方案**：缩到 5 档 width 会把 `params_needed(0.80)` 的插值区间拉宽，
直接削弱"干扰密度↑ → 所需规模↑"这条趋势的分辨力。省 1–2 小时不值得。

## 1. 假设

> **H4-G**：决定参数成本的是**同类干扰项的数量**，不是背景熵。
> 预测：固定其它条件，**提高类元素干扰项密度** → `params_needed(0.80)` 单调上升；
> **提高背景熵但保持零干扰项**（i.i.d 噪声）→ 成本基本不变。

可证伪形式：

| 结果 | 判定 |
|---|---|
| 密度↑ → `params_needed(0.80)` 单调↑（Spearman ρ>0 且 p<0.05），且 C4 不显著高于 C0 | H4-G 成立 |
| C4（噪声，零干扰）同样显著抬高成本 | H4-G 否证（熵本身有效） |
| 两者都不抬高 | H4-G 否证（机制不成立） |

## 4. 统计判据（先锁定，不得事后更换）

1. **主指标**：`params_needed(0.80)` —— 在 log 参数轴上对相邻 width 线性插值；
   未达到 0.80 → 记 `null`（**不**用外推、不用边界值顶替）。
2. **每个 (条件, seed)** 得到一个 `params_needed(0.80)`；条件层面报**中位数**，
   并给 **bootstrap 95% CI**（按 seed 重采样，1000 次）。
3. **单调性**：对密度轴 `0/1/2/4` 做 Spearman（每个 seed 一次，报告 3 个 ρ 与中位数）；
   `p` 值用 `scipy.stats.spearmanr` 的渐近近似；三个 seed 的 p 取中位数。
4. **效应量**：`ratio = params_needed(C3) / params_needed(C0)`，附 bootstrap CI。
   **截断规则**：若 C0 在最小 width（w4）就已 ≥0.80，`params_needed(C0)` 只能记为 `4,208`（`status="left"`），
   此时 `ratio` 是**上界**（真实 C0 需求 ≤ 4,208），报告中必须标注 `ratio ≤ x`，不得写成精确值。
5. **多重比较**：对 C1/C2/C3 三个条件 vs C0 的比较做 Holm 校正（α=0.05）。
6. **缺失值规则**：若某条件在某 seed 上 7 档全部 < 0.80 → 该 seed 记 `null` 并在报告中单列，
   **不得**删掉该 seed 或换 seed 重跑。

---

## 5. 停止规则

1. 126 次跑完即止，**不追加** width、密度点或种子；
2. 若 C0 在最小 width（w4）就饱和（>0.95）→ 该 width 轴对"上升趋势"不敏感，
   如实报告"下限被截断"，**不得调难度重跑**；
3. 若插值区间跨越两个 width 档（过宽）→ 报告区间，不给单点结论；
4. 中途崩溃的格子**只允许原样重跑该格**（同 seed、同配置），不允许换种子或改参数。

---

## 6. 结论边界

- 只回答"类元素干扰密度 vs 背景熵，哪个决定参数成本"；
- **不**用于恢复 `cls` 的颜色证据（M3 已作废该路径，见 C6）；
- **不**用于 H2 的动作空间结论（E1-b 阻塞中）；
- 真实照片背景、真实 GUI 纹理**不在**本次范围；
- 不外推到 ≥10⁹ 参数规模（本实验最大 106K）。

## 7. 干扰项操作化（v1.0 新增，执行前锁定）

### 7.1 为什么"同类干扰"在这里只能是**类元素彩色矩形**

在本环境（6×6 网格、160px）里：

- 每个格子 `20×20`，真实元素宽高约 `int(20*0.40) - U{0..4}` ≈ **4–8 px**；
- `render()` 只在 `(x2-x1) >= 30` 时绘制文字 → **本环境下所有元素都没有文字**；
- 元素颜色由标签决定（`color_by_label=True`），M3 已证明 `cls` 头**几乎完全依赖颜色**（C6）。

因此在本任务中，"与目标同类、需要被区分"的物品 = **同生成过程、同调色板、但颜色不等于目标的
彩色矩形**。文字的语义区分在本分辨率下不存在，这一点必须写进结论（见 §9 边界 B-res）。

### 7.2 干扰项生成规则（与真实元素同分布）

对每个格子，把 `20×20` 的盒分成 2×2 子格（每格 ≈10×10）：

```
k = 该条件的干扰数（0/1/2/4）
取 k 个互不相同的子格（rng.choice(4, k, replace=False)）
每个子格内：
    ew = eh = max(5, int(10*0.55) - U{0..2})     # ≈5–6 px
    ex1 = 子格左 + U{0 .. 子格宽-ew}
    ey1 = 子格上 + U{0 .. 子格高-eh}
    颜色 = PALETTE[U{0..63}]，若等于**本样本目标色**则重抽（最多 8 次）
绘制顺序：背景 → 网格线 → **干扰项 → 真实元素**（真实元素永远在最上层，不会被遮挡）
```

- 干扰项与真实元素的差别**只有颜色**（都带 `(25,25,25)` 描边、同一调色板、同一尺寸量级）；
- 排除目标色是为了避免"存在两个同色物体"的**不可解歧义**（那不是容量问题，是题目坏掉）；
- 排除只针对目标色，不针对其它元素的颜色（保持干扰强度）。

### 7.3 六个条件的唯一差异

| 维度 | 是否随条件变化 |
|---|---|
| 基础任务（标签数组、目标 slot、真实元素几何、指令） | ❌ 完全一致（同一 rng 派生的逐样本基础流） |
| 背景 | ✅ C0–C3 flat；C4 噪声；C5 natural 裁剪 |
| 干扰项数量 | ✅ C0=0、C1=1、C2=2、C3=4；C4/C5=0 |
| 后端 rng（背景/干扰项） | ✅ 每个 (split, 样本 i, 条件) 独立派生，**不回头扰动基础流** |

## 8. 运行协议（锁定）

| 项 | 设定 |
|---|---|
| 训练数据基础种子 | `split_seed=100`（与 P5 同名但**重新生成**，不是复用 P5 的数据） |
| 测试数据基础种子 | `split_seed=999` |
| 逐样本基础 rng | `default_rng(split_seed*100000 + i)` |
| 逐样本背景/干扰 rng | `default_rng(split_seed*100000 + i*13 + cond_idx*7 + 1)` |
| 模型初始化 | `torch.manual_seed(seed)`，`seed ∈ {0,1,2}`；**同一 seed 下所有 width 共用同一初始种子**（width 效应的配对比较） |
| 执行顺序 | 交错：`for width: for seed: for cond(按 (w_idx+s_idx) 轮转)`，避免条件与时间共线 |
| 记录 | 每格一行 jsonl：`cond/width/seed/acc/params/seconds`；另存 `config_fp`、`base_hash`、`img_hash` |
| checkpoint | 不保存权重（与 P5 一致），但必须保存 `config_fp` 与两个数据哈希，保证可复查 |
| 失败处理 | 崩溃格子原样重跑；连续两次失败 → 停止并上报，不得改参数绕过 |

`config_fp` = sha256(`cfg` 的规范化字符串 + 模型构造参数 + 训练超参 + 条件定义版本号)。

## 9. 判定与边界

**判定**（按 §4 口径）：

| 观测 | 结论 |
|---|---|
| Spearman ρ 中位数 > 0 且 p < 0.05，且 C4 与 C0 的 CI 重叠 | **H4-G 成立** |
| C4 显著高于 C0 | **H4-G 否证**（背景熵本身有效） |
| 密度轴无显著上升 | **H4-G 否证**（机制不成立） |

**边界（必须写进报告）**：

- **B-res**：本分辨率下元素无文字（4–8 px），任务靠颜色区分 → 结论只覆盖"颜色/形状特征空间重叠"，不覆盖文字语义；
- **B-col**：C6 已证明颜色是主导线索，因此本实验测的是"**颜色维度的干扰密度**"；
- **B-scale**：最大 106K 参数，不外推到十亿级；
- **B-p5**：P5 只作背景，其 `params_needed` 数值**不得**与本实验并列成表。
