## 1. 假设

> **H4-G**：决定参数成本的是**同类干扰项的数量/相似度**，不是背景熵。
> 泛化预测：固定其它条件，**提高同类干扰项密度** → `params_needed(0.80)` 单调上升；
> **提高背景熵但保持无同类干扰**（i.i.d 噪声）→ 成本基本不变。

**可证伪形式**：

| 结果 | 判定 |
|---|---|
| 干扰密度↑ → `params_needed` 单调↑（Spearman ρ>0 且 p<0.05），且噪声背景下不变 | H4-G 成立 |
| 噪声背景同样显著抬高成本 | H4-G 否证（熵本身有效） |
| 两者都不抬高 | H4-G 否证（机制不成立） |

## 2. 条件（预注册）

| 条件 | 背景 | 同类干扰/格 | 说明 |
|---|---|---|---|
| C0 | flat | 0 | 基线（复用 P5 E0） |
| C1 | flat | 1 | 干扰密度 1 |
| C2 | flat | 2 | 干扰密度 2 |
| C3 | flat | 4 | 干扰密度 4 |
| C4 | iid 噪声 | 0 | 复用 P5 E1（高熵、无同类干扰） |
| C5 | natural 合成 | 0 | 复用 P5 E3（低熵但结构化） |

**主指标**：`params_needed(0.80)` —— 达到 0.80 命中所需的最小 width 对应参数量（P5 已定义该口径）。

**次指标**：各 width 下的 hit 曲线；干扰项与目标的特征空间重叠度（若可计算，作为解释变量，不参与判定）。

---

## 3. 对照与样本

| 项 | 设定 |
|---|---|
| width 扫描 | `{4, 6, 8, 12, 16, 24, 32}`（与 P5 一致） |
| 每点 | 3 个训练种子（0/1/2），`n_train=3000`、`n_test=1000`、20 epochs（与 P5 一致） |
| 任务流 | 固定 seed；每条件记录数据哈希 |
| 运行数 | 6 条件 × 7 width × 3 种子 = **126 次**（上限） |

> 126 次偏多：**若时间受限，先跑 C0–C3（4 条件 × 7 width × 3 = 84）**，C4/C5 用 P5 的既有结果对照（同口径），
> 并在报告里注明"跨文件对照，非同批次"。

---

## 4. 统计方法

- `params_needed` 由插值得到 → 用 3 个种子的中位数报告，并给 bootstrap 95% 区间（按 seed 重采样）；
- 单调性用 Spearman（按条件排序）；多重比较 Holm；
- 必报效应量：`params_needed(C3) / params_needed(C0)`。

---

## 5. 停止规则

1. 达到运行上限即止，**不追加** width 或密度点；
2. 若 C0 在最小 width 就饱和（>0.95）→ 该 width 轴无效，判"无法判断"，不得调难度重跑；
3. 若插值区间跨越两个 width 档（过宽）→ 报告区间，不强行给单点结论。

---

## 6. 结论边界

- 只回答"干扰项密度 vs 背景熵，哪个决定参数成本"；
- **不**用于恢复 `cls` 的颜色证据（M3 已作废，见 C6）；
- **不**用于 H2 的动作空间结论（那是 E1-b 的范围，且 E1-b 目前阻塞）；
- 真实照片背景**不在**本次范围。
