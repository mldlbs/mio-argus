## 0. 这份文档要解决什么

项目已积累 30+ 份机制结果，但核心假设 **H 仍是 D 级**（无大模型臂、无成本测量、无 crossing 曲线）。
本设计把 H 改写成**可被真实实验检验的比较问题**，并给出一份**不训练的可行性审计**：
审计不过，就不启动实验；审计通过，再写正式预注册。

## 1. 先钉死"没否定什么"

### 1.1 当前证据的实际含义

| 判断 | 当前证据 | 等级 |
|---|---|---|
| 闭环观察是长任务的**必要**机制 | P1：ρ=0.3,H=8 时 k=1 1.000 vs k=8 0.0767 | B（无大模型臂） |
| 闭环可以**替代**模型参数规模 | **未检验** | — |
| 小模型能**反超**大模型 | **未检验** | — |
| 当前合成环境能提供有效的 crossing 测量 | M1/M1b **不支持**（无可测窗口；H8/H1=0.02 需 0.25） | 已实测 |
| H4：同类干扰密度抬高规模需求 | 描述性支持，主指标两端截断**不可估** | B |

### 1.2 三条禁止的推理（写进报告纪律）

1. **单步准确率不足 ≠ 闭环没有价值。** 闭环可能靠重观察、纠错、恢复降低长任务失败率；
   是否足以抵消规模差距，**必须有真正的大模型对照**。
2. **M1/M1b 的失败 ≠ H 被否证。** 它们否定的是"在当前合成环境里靠调参/补状态造出测量窗口"，
   不是 H 本身。
3. **`∏m_t` 或 `p^H` 不能当作 crossing 的证据。** 独立步基准只是诊断量，
   不预测真实 rollout，也不构成规模对比。

## 2. H 的可检验改写

把 H 从"信念"改写成**带预算约束的比较命题**。对任务族 `T`（长度 `L`）、成功率判据 `τ`：

> **H-C**：存在任务长度 `L*`，使得 `L > L*` 时
> 小模型 + 闭环策略的**成功率**超过大模型 + 基线策略；
> 且存在 `L**`，使得在达到同一 `τ` 时，小模型闭环的**总成本**更低。

两项必须分开报告、分开判定：

| 名称 | 定义 | 失败形态 |
|---|---|---|
| **能力 crossing** | `∃L*: S_small,closed(L) > S_large,base(L)` 且 CI 不跨 0 | 曲线平行/反向 → 无 crossing |
| **成本 crossing** | `∃L**: C_small,closed(L, τ) < C_large,base(L, τ)` | 闭环的额外观察成本吃掉规模优势 |

> 二者**不得互相替代**。一个结果是"小模型更强"，另一个是"小模型更便宜"；
> 只报其一都算不完整。

---

## 3. 三因子设计

| 因子 | 水平 | 约束 |
|---|---|---|
| **规模** | small / medium / large（≥10×，力争 ≥100×） | 必须是**真实不同规模**的模型，不得用同一模型换宽度冒充 |
| **策略** | 单次观察（开环） / 周期观察（k>1） / 闭环验证+恢复 | 三者**同一套工具权限**、同一动作空间、同一预算口径 |
| **任务长度** | 短 / 中 / 长（长任务必须**真实失败与状态变化**） | 难度需先过预扫描：每档成功率落在**区间内部**，不许地板/天花板 |

**公平性硬约束**（缺一条实验即无效）：

1. 同任务集、同判据、同工具权限、同最大步数；
2. 闭环多出来的观察/验证**必须计入成本**（否则成本 crossing 无意义）；
3. 策略实现不得共享"只有闭环才有"的特权（例如读 DOM/无障碍树），除非基线也有；
4. 任务顺序与随机种子对两臂一致（配对）；
5. 任何"重试"都要计入步数与成本。

---

## 4. 成本口径（必须与成功率同时报）

每个决策记录：

```
params（含 adapter） / 推理 FLOPs / 延迟(ms) / token 数 / 观察次数 / 动作次数
```

由此派生两个量：

- `C(L, τ)` = 达到成功率 τ（或跑满预算）时的**总成本**；
- `CE` = 成本效率 = `Δ成功率 / Δ成本`（相对基线）。

**禁止**只报成功率；也**禁止**用"参数更少"代替"总成本更低"（闭环可能更贵）。

---

## 5. 判据与统计（写进正式预注册前先定死）

1. **主判据**：能力 crossing 与成本 crossing **分别**给出 `L*` / `L**` 的区间估计；
   若在扫描的 L 网格内未出现，报告"未观测到 crossing，网格上限 L_max"——**不外推**；
2. **效应量**：`ΔS(L) = S_small,closed − S_large,base`，配 Wilson/t 区间；
3. **分辨率**：L 的网格必须让"阈值附近不留空档"（H4 的教训），
   且**任何阈值型派生指标先过 `docs/PRESCAN_PROTOCOL.md` 门禁**；
4. **多重比较**：三个 L 档 × 两个 crossing 的族内校正（Holm），预先声明；
5. **等效边界**：若 `|ΔS| < δ`（δ 预先声明，例如 0.05），判"无差异"而不是"更优"；
6. **不做**：看完结果换指标、换种子、加档位。

## 6. 可行性审计 A1–A6（**不训练**，每项有硬门）

| # | 审计项 | 通过条件 | 不过怎么办 |
|---|---|---|---|
| **A1** | 规模对手是否真实存在 | 能获得 ≥10× 的模型臂，**并且**能测其 params/FLOPs（本地权重或 API 均可） | **停止**。不得用合成小模型或同族换宽度冒充大模型臂 |
| **A2** | 环境是否有可测窗口 | 最难条件下成功率落在 [0.2, 0.9] 内部（先跑**不进入主分析**的标定） | 换载体（真实 GUI 或更难任务族），不得降标准 |
| **A3** | 策略对照是否公平 | 五条公平性约束逐条可检查（工具权限/预算/特权/配对/重试计入） | 重写基线策略，不得"给闭环开后门" |
| **A4** | 成本是否可测 | 每次决策都能记录 params/FLOPs/延迟/token/观察数 | 换执行框架；只报成功率的实验不启动 |
| **A5** | 任务是否真实到会产生失败与恢复 | 存在真实失败态、可复位、可客观判分（不仅"看起来成功"） | 用合成环境作**对照臂**，但主结论必须来自真实任务 |
| **A6** | 统计是否可支撑 | 每格任务数足以让预注册的 δ 与区间宽度匹配（先算功效） | 加任务数（不是加模型） |

**审计产物**：`H_CROSSING_FEASIBILITY.md`（逐项 PASS/FAIL + 证据 + 成本估算），
审计 FAIL 时**不写正式预注册、不启动训练**。

## 7. 两个候选载体（先定，再审计）

| 载体 | 优点 | 风险 | 建议 |
|---|---|---|---|
| **真实 GUI 任务**（含失败与状态变化） | 唯一能支撑"长任务真实失败"的地方；外部效度 | 复位难、判分需人工/脚本、成本高、可复现性弱 | **主实验** |
| **合成环境**（现有 6×6 等） | 可控、可复现、便宜、因果干净 | **已被 M1/M1b 证明无长 H 可测窗口** | 仅作**对照/标定臂**，不得作主结论 |

> 现有合成环境**不能**承担主实验——这不是偏好，是 M1/M1b 的实测结论。

## 8. 里程碑与停止规则

```
M0  本设计（v0.1）
M1  可行性审计 A1–A6（不训练）        ← 当前唯一该做的事
M2  审计通过 → 正式预注册 v1.0（判据/网格/预算锁死）
M3  预扫描（门禁 B 模式）→ 通过才跑主矩阵
M4  主矩阵（三因子）→ 报告两个 crossing 或"未观测到"
```

- **M1 现状（2026-11-19）：A1 为 PARTIAL PASS、A2 判 FAIL**——阻塞点不是环境，而是 **small 臂没有定位能力**（`H_CROSSING_SMALL_ARM_AUDIT.md`：0/84，MAE 0.20）。H-Crossing 暂不可建；重训坐标头的前置条件见该文件 §8.3。
- M1 任一门 FAIL → **停**，改载体或改问题，不进入 M2；
- 全程不追加 L 档/种子/模型；
- 现有 P0–P9、H3b、H4、M1/M1b、M3 全部冻结为历史证据，**不参与** H-Crossing 的主分析。

## 9. 不做的事

- 不用现有合成环境跑"大模型"（没有真实对手，等于自证）；
- 不用参数更少代替成本更低；
- 不在审计前写正式预注册；
- 不把能力 crossing 与成本 crossing 合并成一句"小模型更好"；
- 不因审计结论不好看而放宽 A1–A6。
