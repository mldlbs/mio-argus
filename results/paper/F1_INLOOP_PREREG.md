# F1 预注册：用 inloop 数据重训 small 臂（并通过 A0-G6）

> 日期：2026-11-22　状态：**判据先锁定，尚未看结果**
> 前置：`VISION_ABLATION_FINDINGS.md`（v3_real 不看图，根因是数据泄露 168/168）
> 目的：造出一个**真的看图像**的 small 臂，作为 H-Crossing 的合法对手。

---

## 1. 要检验的命题

> 用 inloop 管线（指令不含坐标、同一指令出现在多个位置）重训 `ComputerUseModelV3`，
> 能不能得到一个**依赖图像**的臂（A0-G6 ≥ 0.10）？

这不是能力主张，是**仪器主张**：只问"视觉通路是否成立"，不问"能否反超大模型"。

## 2. 数据与切分（固定）

| 项 | 值 | 理由 |
|---|---|---|
| 数据 | `artifacts/computer_use_inloop`，apps = `qgis,notepad` | 全部可用示范，70 个 task |
| 行列数 | 2892（qgis 2799 / notepad 93） | 带坐标 1364，指令泄露 7.1%（≈随机误匹配） |
| 切分 | `--val-ratio 0.25`，**按 task 切**，seed 42 | 同一屏/同链不进两侧，避免记忆泄漏 |
| 分辨率 | 224（`--img-size 224`, `--head v3`） | 与历史可比；768 需 grid/spatial 头，另立 |

## 3. 训练配置（固定，不得中途改）

| 项 | 值 |
|---|---|
| base ckpt | `computer_use_model_v3_real.pth`（与 inloop_notepad 同源，保证可比） |
| epochs | **30** |
| lr / clip / batch | 1e-4 / 1.0 / 8 |
| seed | 42 |
| 输出 | `artifacts/checkpoints/inloop_f1_all.pth`（不覆盖既有） |
| 运行次数 | **1 次** |

## 4. 判据（先锁定）

| # | 判据 | 阈值 | 类型 |
|---|---|---|---|
| **G6** | 模态有效性：`image_effect / text_effect` | **≥ 0.10** | 主判据（通过/不通过） |
| **G6b** | 图像有用性：换灰图后逐行误差的配对 Δ 95% CI | **CI_low > 0** | 必要条件（见 §7.1） |
| G7 | 动作不退化：val `action_acc` | ≥ majority baseline | 必须满足 |
| G8 | 坐标（描述性）：val `coord_mae_norm` | 报数，对照 0.151（inloop_notepad）/ 0.203（v3_real） | 不设阈值 |
| G9 | 坐标命中（描述性）：val `hit_rate`（按 `target_rect`） | 报数 + `hit_n` | 不设阈值 |

**G6 的参考值**（来自 `VISION_ABLATION_FINDINGS.md`，同一仪器）：
`inloop_notepad` 0.256、`inloop_notepad_long` 0.144、`inloop_qgis` 0.024、
`v3_real` 0.025–0.031。

> 为什么 G6 是主判据：G8/G9 的样本量太小（val 任务的带坐标行可能只有几十条），
> 单独看不可靠；而"看不看图"用 84 条 × 4 条件就能稳定判。
> **不得**因为 G8/G9 好看而把 G6 判为通过，反之亦然。

## 5. 判定与后继（响应树，先登记）

| 结果 | 判定 | 后继（已登记，不需再裁定） |
|---|---|---|
| G6 ≥ 0.10 且 G6b 通过 且 G7 满足 | **PASS** | 记为"small 臂成立（视觉通路已证实）"；随后做 A2 的单步定位评测（216 清单），再谈 H-Crossing |
| G6 ≥ 0.10 但 **G6b 不通过** | **FAIL（噪声式敏感）** | 视觉通路未建立：输出会动但没被用于降低误差 → F1b |
| G6 < 0.10 但 G7 满足 | **FAIL（视觉通路未建立）** | F1b：检查融合/学习率（`--lr`、head-only 预热），**不加数据、不换架构** |
| G6 ≥ 0.10 但 G7 不满足 | **FAIL（能力退化）** | 优先修动作头（类别权重/epoch），视觉结论保留 |
| 均不满足 | **FAIL** | 记录，转 L-METHOD，不为它续命 |

## 6. 边界（不可外推）

1. 单次运行、单 seed、单分辨率 224；
2. 数据以 qgis 为主（2799/2892），结论不能推广到"任意桌面应用"；
3. **PASS 只代表"这个臂真的看图"**，不代表它能定位到 20px，更不代表 crossing；
4. 判定线 0.10 是暂定筛选值（本批观测呈 10× 分离），不是理论阈值。

### 7.1 G6b 的定义（相对量，不设绝对阈值）

对 val 中每条带坐标样本，算逐行误差 `err_orig` 与 `err_gray`，
令 `d = err_gray − err_orig`；用 2000 次 bootstrap 求 d 均值的 95% CI。

| 判定 | 条件 |
|---|---|
| **图像确实有用** | `CI_low > 0`（换灰图误差显著变大） |
| 否则 | 不承认视觉通路（哪怕 G6 通过） |

样本量不足（配对行 < 10）→ 记 `INSUFFICIENT`，不得判 PASS。
