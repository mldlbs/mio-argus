# A2 · small 臂在 216 清单上的单步定位：2.78%

> 日期：2026-11-28　范围：**零训练**，`inloop_f1_all` × 216 条冻结清单 × 3 个分辨率。
> 前置：`F1_RESULTS.md`（该臂已过 G6/G6b，视觉通路成立）
> **结论：6/216 = 2.78%。不是域问题，是精度问题——中位误差 142px，目标是 12px。**

---

## 0. 三句话

1. **域差距为零**：训练见过的 task **2.1%（3/142）**，留出 task **4.1%（3/74）**——没有记忆优势，也没有泛化崩塌。
2. **指令类型无差别**：含引号标签 2.7%（5/188），泛化指令 3.6%（1/28）。
3. **分辨率不是解药**：448 → 0.46%，1024 → 1.39%，都比 224 的 2.78% 差（零样本迁分辨率，模型没见过）。

## 1. 方法

| 项 | 值 |
|---|---|
| 臂 | `inloop_f1_all.pth`（30 ep，qgis+notepad，224 训练） |
| 基准 | `audit_manifest.json` 216 条，判据 `rect_img`（与 UGround/GUI-Actor 同一评分器） |
| 输入 | 原图 1536×864 → resize 到 res×res，与训练一致 |
| 分辨率 | 224（主）/ 448 / 1024（零样本，`interpolate_pos=True`） |
| 耗时 | 224: 27.2s；448: 35.8s；1024: 121.6s |

| 1024 | 3/216 = 1.39% | 零样本，仍更差 |

## 3. 分解（为什么是 2.78%）

| 切法 | 命中 |
|---|---|
| 训练见过的 task | 3/142 = **2.1%** |
| 留出 task | 3/74 = **4.1%** |
| 含引号标签 | 5/188 = 2.7% |
| 泛化指令（无引号） | 1/28 = 3.6% |
| 目标短边 0–10px | 0/62 = 0% |
| 目标短边 10–15px | 6/136 = 4.4% |
| 目标短边 15–25px | 0/14 = 0% |

目标短边中位 **12.0px**；本臂在自域 val 上的中位误差是 **142px**（0.0556 归一）。
**差 12 倍**——这解释了全部失败：不是找不到大致区域，是精度差一个数量级。

## 4. 判定

| 假设 | 数据 | 结论 |
|---|---|---|
| 域偏移 | seen 2.1% vs held-out 4.1% | **否证** |
| 指令类型（泛化指令更难） | 2.7% vs 3.6% | **否证** |
| 分辨率不足 | 448/1024 零样本更差 | **否证**（至少"零样本换分辨率"无效） |
| **定位精度不足** | 中位误差 142px vs 目标 12px | **支持** |

## 5. 对 H-Crossing 的意义

| 项 | 现状 |
|---|---|
| small 臂有视觉通路 | ✅ 已证实（G6 0.639 / 灰图命中归零） |
| small 臂能定位 | ⚠️ 2.78%，是 UGround 的 **1/18** |
| 靠"闭环"补 17 倍差距 | ❌ 不现实：闭环增益在最好的实验里也只有 10–30%（M1b 的 progress 4–7 +0.092） |

⇒ **按原样，H-Crossing 的"小模型反超"在这个臂上不可能成立。**
不是因为它没看图，而是因为它的定位精度低于对手一个数量级。

要么把 small 臂的精度做上去（下列工单），要么承认"10× 规模差下反超"在本项目现有条件下不成立。

## 7. 过程记录：一次仪器错误

首次跑出 **0/216**，原因是 `eval_resolution.py` 把 checkpoint 写死成 `computer_use_model_v3_real.pth`，
`--ckpt` 参数不存在——**评的是旧模型**。补 `--ckpt` 后为 2.78%。

这与本项目反复出现的模式同型：**先确认评的是谁，再读数字**。已修，并保留在此记录。

## 8. 边界

1. 单臂、单次训练；样本量 216（Wilson 半宽约 ±6.7pp，2.78% 的 95% CI ≈ 1.3%–6.0%）；
2. `rect_img` 目标是 1536×864 图像坐标，判据与历史一致；
3. 448/1024 是零样本，**不能**据此说"高分辨率没用"，只能说"零样本换分辨率没用"；
4. 目标集中在 10–15px，只覆盖 click，未测 move/拖拽。
