## 0.5 最终审计：三个必须锁定的细节（v0.2）

### 0.5.1 延迟 1 步的精确定义

**允许 V 使用的信息**：`(s_{k-1}, s_k)`，即**上一次尝试**前后的可见状态。
**禁止**：使用当前尝试的即时结果 `(s_k, s_{k+1})`——那等于没有延迟。

伪代码（每个任务的每一步）：

```
pending = None                      # (before, after) 待裁决
for attempt k in 1..R:
    s_before_k = state
    act()                           # 产生 s_after_k
    if pending is not None:         # 裁决的是**上一次**尝试
        if V(pending.before, pending.after) is reject:
            state = pending.before  # 回滚到上次尝试之前
            continue                # 本次尝试作废，消耗预算
    pending = (s_before_k, s_after_k)
# 本步结束后，最后一次尝试的裁决顺延到下一步（延迟的真实代价）
```

要点：

1. **V 永远看不到当前尝试的结果**（用断言保证：V 的输入里 `after` 的时间戳 < 当前尝试的开始时间）；
2. 回滚以"上次尝试之前"的状态为准，不凭空恢复进度；
3. 延迟带来的代价是**必须消耗一次尝试**才知道对错，这正是要测的退化。

### 0.5.2 测试任务与 rollout seed 固定（不做训练后筛选）

| 项 | 锁定值 |
|---|---|
| rollout seed | `seed = 5000 + 100*cond_idx + H*7 + int(rho*100)`，`cond_idx ∈ {0,1,2}` |
| 两臂 | **同一个 seed**（配对），同条件同 H 的任务流必须逐项一致 |
| 任务数 | 300 / 格 |
| ρ | 0.3（主）、1.0（次，仅报告） |
| 训练数据 | `seed=0`（π 与 V 共用同一批），n=4000 |
| 禁止 | 训练后按结果挑选任务/种子；不得因为某条件不好看而换 seed |

### 0.5.3 判定（不变，重申）

- **泛化支持**：≥ **2/3** 条件上 `Δ(H=8)` 的 95% CI 下限 > 0；
- 若仅 1/3 支持 → 判"部分泛化"，逐条件写明；
- 若 0/3 → 判"不泛化"；
- **不追加条件、不追加种子**。

## 1. 假设

> **H3b-G**：结果验证的增益 `Δ = S(π+V) − S(π)` 在**未见条件**下仍然为正，
> 且随"信号质量下降"单调衰减；当信号噪声超过阈值时失效。

**判定**：

| 结果 | 判定 |
|---|---|
| 未见条件下 `Δ` 的 95% CI 下限 > 0（至少 2/3 条件） | H3b-G 成立（可泛化） |
| 某条件 `Δ` 的 CI 覆盖 0 | 该条件**不泛化**，必须写清边界 |
| 全部条件 CI 覆盖 0 | H3b-G 否证 |

---

## 2. 已见 / 未见条件（预注册）

| 维度 | 已见（P3/P6） | 未见（本次） |
|---|---|---|
| 网格 | 6×6 | **8×8**（元素数 64，熵更高） |
| 信号质量 | 干净 / ε≤0.1 | **ε=0.15**（超出 P6 已测范围） |
| 信号时序 | 立即 | **延迟 1 步** |
| H | 1/2/4/8 | 同（不新增 H 轴，避免混淆） |

**主指标**：`Δ(H=8)`，即长任务上的增益（P3 中效应最大处）。
**次指标**：Δ(H=1..8) 曲线 + 失败模式（V 误判导致的重试次数）。

| 实现 | **新建** `experiments/paper/h3b_generalization.py`（约 150 行）；**不修改** `p3_verifier.py`，P3 历史结果与复现路径保持不变 |

## 4. 统计方法

- 逐条件报告 `Δ` 的配对 t 区间（df=2）；不使用 bootstrap；
- 报告 Δ(H) 斜率是否随噪声单调下降（Spearman）；
- 所有比较用 Holm 校正；效应量（Cliff's δ）必报。

---

## 5. 停止规则

1. 18 次跑完即止；**不追加**条件或种子；
2. 若某条件出现地板（两臂均 <0.05）→ 该条件判"无法判断"，不得调难度重跑；
3. 若 `V` 的阈值在测试集上调过（C5 风险）→ 必须改用验证集选阈值后重跑该格，否则结果作废。

---

## 5.5 实现前的风险登记

| 风险 | 说明 | 处理 |
|---|---|---|
| 工程量比原估大 | 原估"延迟 30 行"，实际需要新 runner（grid 参数化 + 噪声 + 延迟回滚）约 150 行 | 新文件、不动 P3；先在 smoke（1 条件、小样本）验证延迟不泄漏 |
| 8×8 条件下 π 可能学不动 | 64 槽位、熵更高 | 先看 π 单步准确率；若 <0.8 则记 `pi_weak` 并把该条件标"不可解释" |
| V 阈值漂移（C5） | 阈值必须在**验证集**上选 | 沿用 `train_v_calibrated`，禁止在测试集上调 |

## 6. 结论边界

- 只回答"结果验证的增益能否跨条件成立"；
- **不**用于恢复 E1-L，**不**涉及 crossing；
- 若 ε=0.15 或延迟 1 步失效，必须在 `EVIDENCE_GAPS.md` 新增一条**适用边界**（不是否证 H3b 本身）。
