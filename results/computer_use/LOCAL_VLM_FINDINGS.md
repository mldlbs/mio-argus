# 本地 VLM 能力边界实测（qwen3-vl:8b @ Ollama）

> 日期：2026-11-28　范围：**零训练、零成本**，只测吞吐与三种能力：认屏 / 说位置 / 给坐标。
> 触发：讨论"本机能否做 24 小时本地看守"。
> **结论：能"看"能"说"，不能"指"——描述可用（6.2s/屏），坐标定位在 1500 token 内不收敛。**

---

## 0. 三句话

1. **速度陷阱**：Ollama 默认 `num_ctx=262144` → 分配 45 GB → 79% 跑 CPU → 7.3 tok/s。
   设 `num_ctx=8192` 后 → 100% GPU、6.6 GB、**54 tok/s（7.4×）**。
2. **认屏可用**：2560×1440 全图一次 **6.2 秒**，正确识别 QGIS 界面与窗口内容。
3. **给坐标不可用**：216 清单冒烟 **0/5，5 条全部无法解析**（输出全是 thinking，没有数字）。

## 1. 环境与模型

| 项 | 值 |
|---|---|
| Ollama | 0.40.19 |
| 模型 | `qwen3-vl:8b`（6.1 GB，q4） |
| GPU | RTX 3060 12 GB |
| 测试图 | `artifacts/computer_use_inloop/.../frame_000.png`（2560×1440）、清单图（1536×864） |

## 2. 吞吐

| 配置 | 处理器 | 显存 | 速度 | 全屏一次 |
|---|---|---|---|---|
| 默认 `num_ctx=262144` | 79% CPU / 21% GPU | 45 GB | 7.3 tok/s | ≈194 s（CLI，含 thinking） |
| `num_ctx=8192` | **100% GPU** | **6.6 GB** | **54 tok/s** | **6.2 s**（3 624 视觉 token） |

降采样没有收益：视觉 token 有下限（≈1 050），缩到 224/512/1024 都还是 1 050 左右，
而**全分辨率 3 624 token 反而答得更准**（1024 下把 QGIS 认成了 Adobe Illustrator）。

## 3. 三种能力

| 能力 | 结果 | 证据 |
|---|---|---|
| **描述屏幕** | ✅ 可用 | 2560 全图 6.2 s，答出 "QGIS"；CLI 版还正确读出窗口标题与内容 |
| **输出数字** | ⚠️ 要长思考 | "图片右下角坐标是多少" → 14.5 s / 749 token，答 "1536 864"（正确） |
| **给元素坐标** | ❌ 不可用 | 216 清单冒烟 **0/5**，5 条**全部无可解析数字**；1500 token 预算仍被截断 |

给坐标失败的具体形态（`/no_think`、JSON 格式、`think:false` 三种提示都试过）：

```
thinking: "Got it, let's look at the screenshot. The left panel has a Layers section...
           The 'cities' item is in the Layers list. ..."
response: ""            done_reason = length (1500 tokens)
```

模型会**用自然语言猜位置**（"x 大概是图层面板左边 10 像素"），但从不落成坐标。

## 4. 判定：这是"不可测"还是"做不到"

按三态规则，这次要分开写：

| 层 | 判定 |
|---|---|
| 吞吐/显存 | **已测**：能跑，6.2 s/屏，零成本 |
| 描述能力 | **已测**：可用 |
| 坐标定位（本部署） | **UNMEASURABLE**：输出不可解析，等于仪器没接上 |
| 坐标定位（模型本身） | **未测**：不能据此说 qwen3-vl 不会 grounding |

**不得**把 0/5 写成"qwen3-vl 不能定位"——它连格式都没吐出来。这与此前 `v3_real` 0/84 的教训同型：
**先确认仪器，再判主张。**

## 5. 对两件事的影响

### 5.1 本地 24/7 看守

| 用途 | 可行性 |
|---|---|
| 定时看屏幕、识别状态（有没有弹窗、卡住、变英文） | ✅ 6.2 s/次，零成本 |
| 每日总结日志、triage | ✅ `qwen2.5:7b` 3.7 s（热） |
| 看屏幕**并点击某元素** | ❌ 本地 8B 给不出坐标 |

⇒ 看守可以做**"发现异常"**，不能做**"自己动手修"**。动手要么交给规则脚本，要么叫醒远端。

### 5.2 H-Crossing 的 40× 臂

A1 审计把 `qwen3-vl:8b` 定为 40× 臂。本文件说明：**在 Ollama 这个部署下，它不能作为 grounding 臂**。
要救它只有换服务形态（HF `transformers` 5.15.1 原生 `qwen3_vl`、关闭 thinking、或全精度），
否则 40× 这一侧和 `v3_real` 一样"没有可用的手"。
