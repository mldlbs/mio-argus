# Q3 结果：给门控一个"可学"的版本，Q1 的否定会被训练推翻吗？

> 复现：
> ```
> python experiments/plasticity/q3_learned_gate.py --quick
> python experiments/plasticity/q3_learned_gate.py            # 完整协议：150 epoch / 1500 流 / 3 seeds
> ```
> 脚本：`q3_learned_gate.py`　输出：`results/plasticity/q3_learned_gate_results.json`
> 设计：[docs/PLASTICITY.md](..\..\docs\PLASTICITY.md)　前序：[Q1_RESULTS.md](Q1_RESULTS.md) / [Q2_RESULTS.md](Q2_RESULTS.md)

---

## 1. 一句话结论

> **不会。端到端训练后 learned gate 的效应仍是 ≈0（|Δ| ≤ 0.0004），
> "选择性写入是机制"在可学版本下也不成立。**
> learned decay 只在偏近因查询下拿到小的正增益（+0.012 ~ +0.023），
> 与 Q2 的"衰减 = f(查询分布)"一致，但**幅度远小于 Q2 的手工衰减**，
> 也**没有推翻精确有界缓冲**（偏近因下 KV 依然更强）。

---

## 2. 设置

- 可微联想记忆（端到端训练，梯度穿过写入过程）：
  `k = W_k x`，`v = W_v y`；`W ← λ·W + g·(v ⊗ k)/d`；
  读出 `readout(W·(W_q cue))`；损失 `1 − cos(y_hat, y_true)`。
- **2×2 消融**（同参数、同算力，只差 g 与 λ 是否可学）：

  | 臂 | 门控 g | 衰减 λ |
  |---|---|---|
  | A `nogate_nodecay` | ≡1 | ≡1 |
  | B `learnedgate_nodecay` | 可学（3 特征 MLP：surprise / 预测范数 / 写入范数） | ≡1 |
  | C `nogate_ldecay` | ≡1 | 可学（sigmoid 参数化） |
  | D `learnedgate_ldecay` | 可学 | 可学 |

- 非学习参照 `ExactKV`（raw 向量、容量 32，总关联 128 → 必然超容量）。
- 扫描：cue 噪声 `noise ∈ {0, 0.4}` × 查询距离权重 `beta ∈ {1.0, 0.7}`。
- **完整协议**：150 epochs、1500 训练流、400 测试流、3 seeds（RTX 3060，约 133 分钟）。

---

## 3. 结果

### 3.1 全表（3 seeds 平均，加权余弦召回）

noise=0.0：

| 臂 | beta=1.0 | beta=0.7 |
|---|---:|---:|
| A nogate_nodecay | 0.5545 | 0.5548 |
| B learnedgate | 0.5547 | 0.5552 |
| C ldecay | 0.5540 | **0.5775** |
| D both | 0.5539 | **0.5779** |
| ExactKV 参照 | 0.2505 | **0.7628** |

noise=0.4：

| 臂 | beta=1.0 | beta=0.7 |
|---|---:|---:|
| A | 0.2102 | 0.2103 |
| B | 0.2101 | 0.2101 |
| C | 0.2101 | 0.2223 |
| D | 0.2101 | 0.2223 |
| ExactKV 参照 | 0.1611 | **0.4915** |

### 3.2 判据：相对 A 的增量

| 条件 | gate (B−A) | decay (C−A) | both (D−A) |
|---|---:|---:|---:|
| noise=0, beta=1.0 | +0.0002 | −0.0005 | −0.0006 |
| noise=0, beta=0.7 | +0.0004 | **+0.0227** | **+0.0231** |
| noise=0.4, beta=1.0 | −0.0001 | −0.0001 | −0.0001 |
| noise=0.4, beta=0.7 | −0.0002 | **+0.0120** | **+0.0120** |

- **learned gate ≈ 0**：全部 4 个条件 |Δ| ≤ 0.0004。给了梯度、给了端到端目标，
  门控 MLP 仍然学不出"该记什么"——Q1 的杀死条件 3 在训练下**稳健成立**。
- **learned decay 条件性成立**：均匀查询 ≈0，偏近因 +0.012 ~ +0.023。
  方向与 Q2（手工衰减在 beta<0.9 转正）一致，**再次确认"遗忘的价值 = f(查询分布)"**；
  但幅度（+0.023）明显小于 Q2 手工衰减同区间（beta=0.7 时 +0.04 ~ +0.14），
  且 lambda 的可学上界受限于写入-衰减耦合的训练难度（见 §5 局限）。
- **分水岭不变**：均匀/超容量时 fw ≫ KV（0.55 vs 0.25）；
  偏近因时 KV 赢（0.55 vs 0.76；噪声下 0.21 vs 0.49）。
  Q1/Q2 的"压缩记忆优势只在远距离/超容量"结论再次复现。

### 3.3 方法学插曲：quick 跑不可作裁决

`--quick`（1 seed / 40 epochs / 400 流）曾给出 decay = **−0.09 ~ −0.34** 的大负值；
完整协议下同一效应是 **−0.0005 ~ +0.023**。
欠训练时可学衰减会把 λ 压塌、连带投影学不动，产生**虚假的大负效应**。
→ 单 seed quick 只能用于流程冒烟，效应量方向必须以完整协议为准（P9 的多 seed 纪律再证）。

## 4. 对 docs/PLASTICITY.md 判据的更新

| 判据 | Q1 | Q2 | Q3（终） |
|---|---|---|---|
| 门控是机制吗（§5.5 条件 3） | 触发（手工门控≈0） | 不变 | **稳健触发**：可学门控也 ≈0（\|Δ\|≤0.0004） |
| 衰减是机制吗 | 负 | 部分撤回（依赖查询分布） | **维持条件性**：可学版只在偏近因下 +0.012~+0.023 |
| 分水岭 `C > B`（§5.4） | 距离相关 | 收紧 | 不变：超容量均匀时 fw 赢，偏近因 KV 赢 |
| 训练能翻案吗（Q3 独有问题） | — | — | **不能**（对写入门控）；对衰减只是复现条件性 |

**至此 §3 命题的写入侧全部测完**：

> (a) 跨边界召回成立（sanity）；(b) 距离/容量结构成立；
> (c) `C > B` 只在"超容量 + 查询不偏近因"的区域成立。
> **可塑性的独特卖点——选择性写入、遗忘、巩固、可学门控——在本设置里全部未兑现。**
> 站得住的只剩一句：**压缩式状态是容量受限时的召回工程，不是新机制。**

## 5. 局限

- 任务仍是单向量联想（n=64、E=16、M=8）；"重要性"只体现为查询分布，没有任务相关重要性。
- learned gate 的输入特征（surprise/范数）是手工设计的；"学一个写入控制器"的更大形态
  （如用读出误差反传的两阶段写入）未测——但那已改变等算力约束。
- lambda 与投影联合训练存在耦合（先降 λ 则 W 梯度变小），可学衰减可能**被低估**；
  给 λ 一个 warm-up / 分离学习率或可部分缓解，未做。
- ExactKV 用 raw 向量 + 余弦检索（非学习），learned 臂用学习投影——跨族比较，
  绝对值不宜直接比；结论只用同族内增量。
